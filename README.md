# MCP-for-Calibre-Ebook-Translator
为Calibre-Ebook-Translator添加第三方的MCP支持



自动识别插件Ebook-Translator的翻译缓存，直接读写数据库获取翻译chunk。

pip install mcp

python 你的路径-ebook_translator_mcp.py --selftest
